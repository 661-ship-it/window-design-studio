# Window Design Studio 用户操作手册

本手册对应仓库根目录的 index.html。界面按钮和功能以当前程序为准。

## 1. 打开工作台

- 在线使用：访问 https://661-ship-it.github.io/window-design-studio/ 。如果页面暂时打不开，请稍后重试，或检查仓库 Pages 部署状态。
- 本地使用：下载仓库中的 index.html，使用较新版本的 Chrome 或 Edge 打开。程序没有外部资源依赖。

建议使用桌面浏览器。工具栏项目较多，窗口较窄时可横向滚动工具栏。

## 2. 创建门窗组件

1. 在左侧“组件与绘图元素”区域点击“窗”或“门”标签。
2. 点击需要的组件名称，组件会添加到画布中心附近；也可以按住组件卡片拖到画布中的目标位置。
3. 左侧“图层树 · Scene Objects”会列出图纸中的对象。新建对象会自动选中。
4. 选中组件后，在右侧“对象属性”中调整编号、位置 X/Y、旋转、宽度和高度。宽高单位为 mm，超出组件允许范围时程序会提示。
5. 可继续设置开启方向、开启类型、玻璃、拼角、填充颜色和组件图层。组件图层中的复选框控制显示，旁边的下拉框和数值框控制颜色及线宽。

补充：左内开窗的左右开启方向按“从室内侧看”定义。选中横向百叶窗后，可在“横向百叶参数”中设置 3–20 片叶片，并单独开关玻璃边界。两轨推拉窗/门及双扇推拉门会在属性区说明立面箭头所表示的移动方向。

组件库包含固定窗、左内开窗、上悬窗、下悬窗、单提拉窗、双扇平开窗、双提拉窗、百叶窗、两轨推拉窗，以及单开门、双开平开门、单扇推拉门、双扇推拉门和两轨推拉门。

组件的玻璃选项目前是配置记录，不区分玻璃层数或材质；门扇现有的单玻、中空双玻和钢化玻璃设置均显示玻璃边界，不代表具体工程构造。

## 3. 选择、移动、复制和删除

- 在画布上单击对象即可选择；按住 Shift 再单击可多选。也可以点击左侧图层树中的对象名称进行选择。
- 使用“选择”工具拖动对象，可移动对象。画布空白处拖动可移动画布。
- 点击“复制”创建副本；快捷键 Ctrl+C（Mac 上为 Command+C）也可复制所选对象。
- 选择对象后点击“删除”或按 Delete / Backspace 删除。
- “对象删除”工具可通过点击对象直接删除它。

## 4. 组合、翻转、旋转和对齐

- 按住 Shift 选择至少两个对象，点击“组合”。选择组合对象后点击“取消组合”。
- 使用“左右翻转”或“上下翻转”翻转所选对象。
- 选中单个对象时，可在右侧“旋转”输入角度；多选时可在整体旋转字段输入角度。
- 多选后，在工具栏对齐方式下拉框选择左对齐、水平居中、顶对齐或垂直居中，再点击“对齐”。

## 5. 绘图工具

点击工具栏对应按钮后，在画布上按下并拖动完成绘制：

- “直线”“虚线”“矩形”“圆角矩形”“圆”“三角形”。
- 绘制直线或虚线时按住 Shift 可约束为水平或垂直方向。
- 选中形状后，可在右侧属性面板修改宽高、线条颜色、线宽、透明度以及适用的填充、圆角或虚线间隔。

左侧“形状”标签中的形状项目也可点击以启用对应绘图工具。

## 6. 文字、尺寸和符号

- 左侧“文字”标签中点击文字项目，或点击工具栏“文字”，添加文字对象；在右侧属性中编辑文字内容、字号、颜色和粗细。
- 先选中一个门窗组件，再点击工具栏“宽度尺寸”或“高度尺寸”，会创建关联标注。标注会随组件移动和宽高变化自动更新；在右侧可调整标注偏移和样式。删除组件时，关联的宽、高标注也会删除。
- 未选中组件时点击“宽度尺寸”或“高度尺寸”，会创建独立尺寸线；可在右侧调整长度、标注值、字号、字体、颜色和线宽。
- 左侧“符号”标签提供尺寸线、开启符号和室内外标识。点击项目添加，再在右侧属性中编辑可用参数。

## 7. 擦除工具

- “对象删除”：点击一个对象将其删除。
- “橡皮擦”：在画布上拖动擦除图形显示。选中橡皮擦后，右侧“像素橡皮擦”面板可调整大小、形状（圆形/方形）和透明度；“清除全部擦除”会移除所有擦除笔迹。
- 擦除操作可使用“撤销”恢复。

## 8. 撤销、重做和画布视图

- 点击顶部“撤销”或“重做”；也支持 Ctrl+Z / Ctrl+Y（Mac 上为 Command+Z / Command+Y）。
- 鼠标滚轮缩放画布；工具栏“移动”可拖动画布；“适合”可将现有图形缩放到合适视图。
- 工具栏“吸附”按钮可开关对象移动时的对齐吸附。状态栏显示坐标和缩放比例。

## 9. 导出 PNG 或 PDF

- 点击顶部“SVG”导出透明背景的 SVG 矢量图。
- 点击顶部“白底 PNG”导出白色背景图片。
- 点击“透明 PNG”导出透明背景图片。
- 点击“打印 PDF”打开浏览器打印对话框，在打印机选项中选择“另存为 PDF”或系统提供的 PDF 输出项。打印选项因浏览器和系统而异。

导出前先确认画布中的对象完整、位置合适。PNG 只保存当前图纸图像，不包含可编辑工程数据。

## 10. 保存与备份

当前没有自动保存或可编辑工程文件保存功能。图纸仅存在于当前打开的页面中；刷新、关闭页面或确认“新建”清空图纸后，内容会丢失。需要保留成果时，请及时导出 PNG，并将文件另存到自己的位置。PNG 不能重新导入为可编辑图纸。

## 11. 常见问题

**组件拖入画布后看不到？**  
确认拖动时鼠标释放在中间白色画布范围内。也可以改为点击左侧组件卡片创建。创建后可点“适合”查看全部图形。

**组件显示很小或跑到视野外？**  
点击工具栏“适合”。也可以用鼠标滚轮缩放、用“移动”拖动画布。

**导出按钮没有生成图片？**  
请先在画布添加对象；空白图纸不会导出。检查浏览器是否拦截了下载，并确认浏览器版本较新。

**如何获得 PDF？**  
点击“打印 PDF”，在系统打印对话框选择 PDF 保存选项。

**刷新后图纸消失？**  
程序当前不自动保存。刷新前请先导出 PNG；PNG 是图片备份，不能继续编辑。

**在线页面无法访问？**  
仓库 Pages 未配置或刚保存配置时，首次部署可能需要等待。检查仓库 Settings → Pages 中是否选择 main 分支和 /(root)，并查看部署状态。
