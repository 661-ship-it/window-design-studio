# Window Design Studio V1.2 Elevation Update Plan

> Inline execution in the user-approved V1.2 branch. The attached V1.2 taskbook is the implementation specification.

**Goal:** Parameterize and correct the existing 14 front-elevation components without changing their IDs, names, kinds, defaults, colors, joint defaults, or unrelated application behavior.

**Architecture:** Keep the single-file HTML/SVG implementation. Add shared dimension-relative geometry helpers and per-component drawing branches within the existing `componentSVG()` path. Add only the needed component properties and render controls; preserve `objectSVG()` as the shared renderer for canvas, SVG/PNG export, and print.

**Tech Stack:** HTML, native JavaScript, SVG, Node.js smoke tests, isolated Chrome/CDP.

## Global Constraints

- Keep all 14 component IDs, names, kinds, default dimensions, and edit ranges unchanged.
- Front elevation only; no plan view, thickness, track cross-section, or profile section.
- Preserve blue fill `#005BAC`, user-editable colors, fill behavior, and V1.1 joint defaults.
- No automatic recoloring, no unrelated refactor, no changes to `main`, no auto-merge.
- Treat dimensions as visual drawing parameters, not manufacturing or code-standard values.
- Pause any unresolved geometry or door/glass semantics and ask the user before implementing that item.

## Files

- Modify `index.html`: relative geometry, component SVG, and kind-specific properties.
- Extend `tests/v1.1-smoke.mjs` or add a V1.2 browser test: rendered bounds, ratios, properties, undo/redo, and export output.
- Add `docs/V1.2_PRECHECK_REPORT.md`, `docs/screenshots/v1.2-before/*.png`, `docs/V1.2_CHANGE_REPORT.md`, and after-phase screenshots.
