# 门窗 CAD 在线设计工作台

这是一个以 HTML、原生 JavaScript 和 SVG 实现的轻量级二维门窗绘图工具。面向门窗方案设计、基础门窗示意图和二维图形表达，打开网页即可使用，不需要安装传统 CAD 软件，也不依赖 AI 模型或云端登录服务。

## 当前功能

功能依据当前 index.html 源码整理：

- 门窗组件库：9 种窗（固定窗、左内开窗、上悬窗、下悬窗、单提拉窗、双扇平开窗、双提拉窗、百叶窗、两轨推拉窗）和 5 种门（单开门、双开平开门、单扇推拉门、双扇推拉门、两轨推拉门）。
- 点击组件库项目即可创建；也可将组件拖到画布指定位置。
- 选择和移动对象；Shift + 单击可多选。可在属性面板编辑组件位置、宽高、旋转、开启方向、开启类型、玻璃、拼角、颜色和图层显示等参数。
- 复制、删除、组合、取消组合、左右/上下翻转；多选对象支持整体旋转和对齐。
- 绘图工具：直线、虚线、矩形、圆角矩形、圆、三角形；另有文字、尺寸线、开启符号和室内外标识。
- 两种擦除工具：对象删除（点击对象删除）和橡皮擦（圆形/方形、大小与透明度可调，并可清除全部擦除笔迹）。
- 撤销、重做、画布移动、滚轮缩放、适合视图和对象吸附。
- 导出白底 PNG、透明 PNG；通过浏览器打印功能输出 PDF。
- 组件默认框线、扇框线、玻璃框线、五金、开启符号、尺寸标注和拼角线均为黑色 1 px；组件填充和图层属性可在属性面板调整。

## 使用环境

推荐使用桌面版 Chrome 或 Microsoft Edge 的较新版本。程序为单个 HTML 文件，样式、脚本和 SVG 绘制逻辑都在文件内，没有外部 CSS、JavaScript、字体或图片依赖。下载 index.html 后可在本地浏览器打开；使用在线版时，首次加载需要联网访问 GitHub Pages，之后页面本身不需要调用在线服务。PDF 输出由浏览器打印对话框完成。

手机屏幕空间有限，建议在电脑上进行完整设计。

## 图纸保存与备份

当前程序没有自动保存，也没有 localStorage 或可编辑工程文件保存/导入功能。图纸只存在于当前页面运行期间；刷新、关闭页面或点击“新建”清空后，未导出的内容无法恢复。

请及时使用“白底 PNG”或“透明 PNG”导出图像备份。PNG 是图纸图片，不是可继续编辑的工程文件；程序当前没有可编辑图纸的备份方式。
